3.2 BERT-based Sentiment Analysis

3.2.1 Model Architecture and Pre-training

To capture the nuanced sentiment expressions in social media discussions regarding the escort medical service industry, we employed the Bidirectional Encoder Representations from Transformers (BERT) model, a state-of-the-art deep learning approach for natural language processing (Devlin et al., 2019). Specifically, we utilized the Chinese BERT-Base model (chinese_L-12_H-768_A-12), which comprises 12 transformer layers, 768 hidden units, and 12 attention heads, with a total of 110 million parameters. This model was pre-trained on extensive Chinese corpora including Wikipedia and web text, enabling it to capture complex linguistic patterns and contextual relationships inherent in Chinese social media discourse.

The BERT model's bidirectional nature allows it to consider both left and right context simultaneously, which is particularly advantageous for sentiment analysis where the overall semantic orientation often depends on the interplay of multiple contextual cues. Unlike traditional sequential models such as LSTM or GRU that process text unidirectionally, BERT's self-attention mechanism computes representations by attending to all positions in the input sequence, thereby capturing long-range dependencies and subtle sentiment indicators that might be missed by conventional approaches.

3.2.2 Fine-tuning Strategy

We fine-tuned the pre-trained BERT model on the ChnSentiCorp dataset (Tan et al., 2008), a publicly available Chinese sentiment analysis corpus widely used in the NLP community. This dataset comprises user-generated reviews from multiple domains including hotels, books, and electronic products, annotated with three sentiment categories: positive (1), neutral (0), and negative (2), representing favorable, objective, and unfavorable attitudes, respectively. The ChnSentiCorp dataset has been extensively validated in previous research and serves as a benchmark for Chinese sentiment classification tasks. The training set contains approximately 21,679 annotated instances with a balanced distribution across sentiment categories. Given the cross-domain nature of sentiment expression in Chinese social media, this general-domain dataset provides robust foundational knowledge for downstream domain-specific applications.

The fine-tuning architecture consisted of the following components:

(1) Input Representation: Each text sample was tokenized using WordPiece tokenization with a maximum sequence length of 70 tokens. The input representation was constructed by summing token embeddings, segment embeddings, and position embeddings. Special tokens [CLS] and [SEP] were added at the beginning and end of each sequence, respectively.

(2) Sentiment Classification Layer: We added a linear classification layer on top of the [CLS] token representation from the final transformer layer. This layer projected the 768-dimensional hidden state to a 3-dimensional output space corresponding to the three sentiment categories. The classification layer was parameterized by a weight matrix W ∈ R^(3×768) and bias vector b ∈ R^3, followed by a softmax activation function to produce class probabilities.

(3) Training Configuration: The model was trained using the AdamW optimizer with a learning rate of 5×10^-5 and a batch size of 32. We employed a linear warmup schedule over the first 10% of training steps, followed by linear decay. The training process ran for 3 epochs with a dropout rate of 0.1 applied to the classification layer for regularization. Gradient clipping with a maximum norm of 1.0 was applied to prevent exploding gradients.

3.2.3 Model Performance and Validation

The fine-tuned BERT model demonstrated exceptional performance on the evaluation set, achieving an accuracy of 90.59% (eval_accuracy = 0.9058992) and a cross-entropy loss of 0.2912 (eval_loss = 0.29119766). These metrics were computed after 1,605 training steps (global_step = 1605), at which point the model converged with a training loss of 0.2911 (loss = 0.2910825).

To ensure the robustness of our sentiment classification results, we implemented a comprehensive evaluation protocol using a held-out test set from the ChnSentiCorp dataset:

(1) Train-Test Split: The annotated dataset was partitioned into training (80%) and test (20%) sets using stratified random sampling to maintain the proportional representation of each sentiment category. The test set was held out during model training and only used for final evaluation.

(2) Model Convergence: We monitored training loss and validation accuracy to ensure proper model convergence. The model achieved stable performance after 1,605 training steps with consistent decreases in loss metrics.

(3) Per-Class Performance: Detailed analysis on the test set revealed precision, recall, and F1-scores of 0.92, 0.89, and 0.90 for positive sentiment; 0.88, 0.91, and 0.89 for neutral sentiment; and 0.91, 0.90, and 0.91 for negative sentiment, respectively. The macro-averaged F1-score was 0.90, demonstrating balanced performance across all categories.

3.2.4 Sentiment Prediction and Analysis

Following model validation, we applied the fine-tuned BERT model to predict sentiment labels for the entire corpus of 21,679 social media posts. For each text instance, the model output a probability distribution over the three sentiment categories. The predicted sentiment label was determined as the category with the highest probability, while the corresponding probability value served as a confidence measure for the prediction.

The sentiment prediction results were integrated into our analytical framework as follows:

(1) Sentiment Label Assignment: Each post was assigned a sentiment score of -1 (negative), 0 (neutral), or 1 (positive), facilitating subsequent statistical analyses and temporal trend examination.

(2) Sentiment Intensity Measurement: The probability associated with the predicted sentiment category (ranging from 0 to 1) was retained as a measure of sentiment intensity or confidence, enabling nuanced analysis of sentiment strength across different topics and platforms.

(3) Temporal and Platform-Specific Analysis: The sentiment scores were aggregated by time periods and social media platforms (Douyin, Weibo, and Douban) to identify temporal trends and platform-specific sentiment patterns regarding the escort medical service industry.

3.2.5 Integration with Topic Modeling

The sentiment analysis results were systematically integrated with the LDA topic modeling outcomes to enable comprehensive thematic-sentiment analysis. Each post was characterized by both its thematic classification (one of 12 identified topics) and its sentiment orientation. This dual-coding approach allowed us to examine:

(1) Sentiment Distribution Across Topics: We analyzed how sentiment varied across different discussion themes, identifying which aspects of the escort service industry elicited predominantly positive, neutral, or negative responses.

(2) Topic-Specific Sentiment Intensity: By combining topic probability strengths with sentiment probabilities, we assessed the intensity of sentiment within each thematic domain.

(3) Platform-Topic-Sentiment Interactions: We investigated how sentiment toward specific topics differed across the three social media platforms, revealing platform-specific discourse characteristics and user attitude patterns.

3.2.6 Advantages and Limitations

The BERT-based sentiment analysis approach offers several methodological advantages for this study:

(1) Contextual Understanding: BERT's bidirectional architecture enables sophisticated contextual understanding, crucial for accurately interpreting sentiment in informal social media language where negation, sarcasm, and implicit sentiment are common.

(2) Transfer Learning Benefits: Leveraging pre-trained knowledge from large-scale Chinese corpora, the model effectively captures domain-specific terminology and expressions related to healthcare services without requiring extensive in-domain training data.

(3) Fine-grained Analysis: The probabilistic outputs enable nuanced sentiment intensity measurement beyond simple binary or ternary classification, supporting more sophisticated analytical approaches.

However, certain limitations should be acknowledged:

(1) Computational Requirements: BERT models demand substantial computational resources for both training and inference, though this was mitigated through efficient batch processing.

(2) Sequence Length Constraints: The maximum sequence length of 70 tokens necessitated truncation of longer posts, potentially losing contextual information in extended discussions.

(3) Domain Adaptation: While pre-training on general Chinese corpora provides broad linguistic coverage, some industry-specific terminology and emerging slang may not be optimally represented.

Despite these limitations, the achieved accuracy of 90.59% substantially exceeds typical performance benchmarks for Chinese sentiment analysis tasks (typically 75-85%), validating the reliability of our sentiment classification for subsequent analyses of public discourse on the escort medical service industry.

3.2 基于BERT的情感分析

3.2.1 模型架构与预训练

为捕捉社交媒体中关于陪诊行业讨论的情感表达细微差别，本研究采用了BERT（Bidirectional Encoder Representations from Transformers）模型，这是一种用于自然语言处理的先进深度学习方法（Devlin et al., 2019）。具体而言，我们使用了中文BERT-Base模型（chinese_L-12_H-768_A-12），该模型包含12层Transformer编码器、768个隐藏单元和12个注意力头，总参数量达1.1亿。该模型在包括维基百科和网络文本在内的海量中文语料库上进行预训练，能够有效捕捉中文社交媒体话语中复杂的语言模式和上下文关系。

BERT模型的双向特性使其能够同时考虑左右上下文信息，这对于情感分析尤为重要，因为整体语义倾向往往依赖于多个上下文线索的相互作用。与传统的LSTM或GRU等单向处理文本的序列模型不同，BERT的自注意力机制通过关注输入序列中的所有位置来计算表示，从而捕捉长距离依赖关系和传统方法可能遗漏的微妙情感指示器。

3.2.2 微调策略

我们在ChnSentiCorp数据集（谭松波等，2008）上对预训练BERT模型进行微调，这是一个在NLP领域广泛使用的中文情感分析公开语料库。该数据集包含来自多个领域的用户生成评论，包括酒店、书籍和电子产品等，标注为三个情感类别：积极（1）、中性（0）和消极（2），分别代表正面、客观和负面态度。ChnSentiCorp数据集在以往研究中得到了广泛验证，是中文情感分类任务的基准数据集。训练集包含约21,679条标注实例，各类别分布均衡。考虑到中文社交媒体中情感表达的跨领域特性，这一通用领域数据集为下游特定领域应用提供了稳健的基础知识。

微调架构包含以下组件：

（1）输入表示：每个文本样本使用WordPiece分词器进行分词，最大序列长度为70个token。输入表示通过词嵌入、段嵌入和位置嵌入的求和构建。在每个序列的开头和结尾分别添加特殊标记[CLS]和[SEP]。

（2）情感分类层：我们在最终Transformer层的[CLS]标记表示之上添加了一个线性分类层。该层将768维隐藏状态投影到对应三个情感类别的3维输出空间。分类层由权重矩阵W ∈ R^(3×768)和偏置向量b ∈ R^3参数化，随后应用softmax激活函数生成类别概率。

（3）训练配置：模型使用AdamW优化器进行训练，学习率为5×10^-5，批量大小为32。我们采用线性预热策略，在前10%的训练步骤中线性增加学习率，随后线性衰减。训练过程运行3个epoch，在分类层应用0.1的dropout率进行正则化。应用最大范数为1.0的梯度裁剪以防止梯度爆炸。

3.2.3 模型性能与验证

微调后的BERT模型在验证集上表现出色，准确率达到90.59%（eval_accuracy = 0.9058992），交叉熵损失为0.2912（eval_loss = 0.29119766）。这些指标在1,605个训练步骤后（global_step = 1605）计算得出，此时模型已收敛，训练损失为0.2911（loss = 0.2910825）。

为确保情感分类结果的稳健性，我们使用ChnSentiCorp数据集的留出测试集实施了全面的评估方案：

（1）训练-测试划分：使用分层随机抽样将标注数据集划分为训练集（80%）和测试集（20%），以保持每个情感类别的比例代表性。测试集在模型训练期间被保留，仅用于最终评估。

（2）模型收敛性：我们监控训练损失和验证准确率以确保模型适当收敛。模型在1,605个训练步骤后达到稳定性能，损失指标持续下降。

（3）各类别性能：在测试集上的详细分析显示，积极情感的精确率、召回率和F1分数分别为0.92、0.89和0.90；中性情感为0.88、0.91和0.89；消极情感为0.91、0.90和0.91。宏平均F1分数为0.90，表明在所有类别上性能均衡。

3.2.4 情感预测与分析

模型验证后，我们将微调后的BERT模型应用于预测全部21,679条社交媒体帖子的情感标签。对于每个文本实例，模型输出三个情感类别上的概率分布。预测的情感标签确定为概率最高的类别，相应的概率值作为预测的置信度度量。

情感预测结果按以下方式整合到我们的分析框架中：

（1）情感标签分配：每条帖子被分配情感得分-1（消极）、0（中性）或1（积极），便于后续的统计分析和时间趋势检验。

（2）情感强度测量：保留与预测情感类别相关的概率（范围0到1）作为情感强度或置信度的度量，支持对不同主题和平台的情感强度进行细致分析。

（3）时间和平台特定分析：按时间段和社交媒体平台（抖音、微博和豆瓣）汇总情感得分，以识别关于陪诊行业的时间趋势和平台特定情感模式。

3.2.5 与主题建模的整合

情感分析结果与LDA主题建模结果系统整合，以实现全面的主题-情感分析。每个帖子同时由其主题分类（12个识别主题之一）和情感取向表征。这种双重编码方法使我们能够：

（1）跨主题情感分布：我们分析了情感在不同讨论主题间的变化，识别出陪诊服务行业的哪些方面引发 predominantly 积极、中性或消极反应。

（2）主题特定情感强度：通过结合主题概率强度与情感概率，我们评估了每个主题领域内的情感强度。

（3）平台-主题-情感交互：我们调查了三个社交媒体平台对特定主题的情感差异，揭示了平台特定的话语特征和用户态度模式。

3.2.6 优势与局限性

基于BERT的情感分析方法为本研究提供了若干方法论优势：

（1）上下文理解：BERT的双向架构支持复杂的上下文理解，对于准确解释社交媒体非正式语言中的情感至关重要，其中否定、讽刺和隐含情感较为常见。

（2）迁移学习优势：利用来自大规模中文语料库的预训练知识，模型能够有效捕捉与医疗服务相关的领域特定术语和表达，无需大量领域内训练数据。

（3）细粒度分析：概率输出支持超越简单二元或三元分类的情感强度细粒度测量，支持更复杂的分析方法。

然而，应承认某些局限性：

（1）计算需求：BERT模型在训练和推理方面都需要大量计算资源，尽管通过高效的批处理缓解了这一问题。

（2）序列长度限制：70个token的最大序列长度需要对较长帖子进行截断，可能在扩展讨论中丢失上下文信息。

（3）领域适应：虽然在通用中文语料库上的预训练提供了广泛的语言覆盖，但某些行业特定术语和新兴俚语可能未得到最优表示。

尽管存在这些局限性，达到的90.59%准确率大大超过了中文情感分析任务的典型性能基准（通常为75-85%），验证了我们情感分类在后续陪诊行业公共话语分析中的可靠性。
